# Security Policy

## Supported Scope

We prioritize user security and privacy above all. Because this repository serves as a directory of software and online services, security considerations primarily relate to:

1. **Compromised Software Entries**:
   - Any listed software found to contain malicious code, backdoors, severe unpatched vulnerabilities, or covert data tracking.
2. **Repository Integrity**:
   - Malicious links, phishing redirects, or typosquatting domains in our links.

---

## Reporting a Vulnerability or Malicious Tool

If you discover that an application listed in this repository has introduced malicious behavior, compromised its privacy guarantees, or if you spot a malicious URL within this repo:

1. **Please do NOT open a public issue** if reporting a zero-day vulnerability in third-party software that requires coordinated disclosure.
2. Report the finding by opening a **Private Vulnerability Report** via GitHub:
   - Navigate to the repository's **Security** tab.
   - Click **Report a vulnerability**.
3. Alternatively, contact the maintainers directly at:
   - **Email**: `security@theprivacyfirst.org`

### What to Include in Your Report:
- The name of the software and link listed in `README.md`.
- Detailed description of the privacy violation, backdoor, or security risk.
- Public proofs, security advisories (CVE), or reproducible technical evidence.

---

## Response Timeline

- **Initial Response**: Within 48 hours acknowledging receipt of your report.
- **Investigation & Action**: Within 3-5 business days. If verified, the malicious or compromised entry will be removed immediately from the directory.

# 🗺️ Project Roadmap & Expansion Plan

This document outlines the strategic vision, planned expansions, category development, and technological infrastructure for **Privacy-First Alternatives**.

---

## 🎯 Vision & Goals

Our vision is to build GitHub's definitive, community-maintained, unbiased catalog of privacy-respecting, open-source software, making it simple for people, students, and businesses to migrate away from Big Tech surveillance and closed proprietary silos.

---

## 📅 Roadmap Milestones

### Milestone 1: Core Foundation & Taxonomy (Completed ✅)
- [x] Initial repository setup with Git configuration.
- [x] Curate top 150+ applications across 26 major categories.
- [x] Transition to standardized, readable list format with official website and open-source repository links.
- [x] Add Azokle Privacy suite (Azokle Authenticator in 2FA, Azokle Weather in Weather, Azokle Browser, Azokle Search).
- [x] Establish repository governance: `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, and GitHub issue/PR templates.
- [x] Configure automated git author synchronization for multi-account management.

### Milestone 2: Breadth Expansion (Current Phase 🚀)
- [x] Expand taxonomy from 57 to **75 categories** covering **250+ applications**.
- [x] Incorporate niche digital domains:
  - Fitness & Biometric tracking (Gadgetbridge, RunnerUp)
  - Game streaming & Remote play (Moonlight & Sunshine)
  - System sweepers & Disk analyzers (BleachBit, Czkawka)
  - Open ERP & CRM (ERPNext, Twenty, SuiteCRM)
  - Home inventory & Meal management (Grocy, Mealie)
  - Genealogy & Family trees (Gramps)
  - Audio plugins & VSTs (Surge XT, Vital)
  - Link shorteners & Self-hosted status pages (Dub.co, Shlink, OneUptime)

### Milestone 3: Automated Quality & Health Checks (Next Up ⚙️)
- [ ] **GitHub Actions Link Checker**: Implement automated scheduled CI action (`lychee` or `markdown-link-check`) to detect 404 broken URLs weekly.
- [ ] **License & Telemetry Audit**: Set up an automated check verifying repository activity, OSI license compliance, and issue tracking.
- [ ] **Interactive Web Directory**: Launch a static documentation portal (powered by Astro or Starlight) on GitHub Pages with instant fuzzy searching and category filters.

### Milestone 4: Community & Decentralization (Future 🌐)
- [ ] **Fediverse Integration**: Automated release bot posting privacy updates on Mastodon and Lemmy.
- [ ] **Localized Translations**: Community-led translations of the directory into Spanish, German, French, Hindi, and Mandarin.
- [ ] **Self-Hosting Guide / One-Click Templates**: Include Docker Compose snippets for top self-hosted alternatives (Immich, Vaultwarden, Nextcloud, Actual Budget, Paperless-ngx).

Community members are encouraged to research and propose candidates for:
1. **Bioinformatics & Scientific Computing** (SPSS/SAS alternatives -> R, Jamovi, PSPP)
2. **CAD, Architecture & CAM** (AutoCAD / SolidWorks alternatives -> FreeCAD, LibreCAD, OpenSCAD)
3. **Medical Records & Practice Management** (Epic / Cerner alternatives -> OpenEMR, GNU Health)
4. **Point of Sale (POS) & Retail Systems** (Square / Clover alternatives -> Floreant POS, uniCenta)
5. **Digital Forensics & Incident Response** (Autopsy, Sleuth Kit)
6. **Smart Watch OS & Open Wearables** (AsteroidOS, Bangle.js)
7. **Educational Management & LMS** (Canvas / Blackboard alternatives -> Moodle)
